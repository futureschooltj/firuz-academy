# Firuz-Academy — роҳнамои насб (аз телефон, бе компютер)

Ин барнома мисли «Future School Teacher» сохта шудааст: Firebase (вуруд + пойгоҳи додаҳо) + GitHub Actions (APK месозад) + версияи веб барои Chrome. **Play Market лозим нест.**

## Дар қуттӣ чӣ ҳаст
| Файл | Вазифа |
|---|---|
| index.html | Тамоми барнома (интерфейс + мантиқ) |
| main.js | Пайвастшавӣ ба Firebase ва Android |
| firebase-config.js | **Шумо маълумоти Firebase-и худро дар ин ҷо менависед** |
| firestore.rules | Қоидаҳои амният (дастрасии ҳар курс дар сервер санҷида мешавад) |
| manifest.json, sw.js | Версияи веб (PWA) |
| package.json, capacitor.config.json | Танзимоти APK |
| make_icons.py | Нишони барнома |
| build-apk.yml | Фармони сохтани APK (ба `.github/workflows/build-apk.yml` гузоред) |

## Қадамҳо
1. **Firebase:** лоиҳаи нав созед (метавонед лоиҳаи пештараи `future-school-83763`-ро истифода баред — ҳисобҳо ҷудо мемонанд, чунки почтаи вуруд `@physicsacademy.app` аст, аммо беҳтар аст лоиҳаи нав бошад, то қоидаҳо ба Future School халал нарасонанд).
   - Authentication → Sign-in method → **Email/Password** фаъол кунед.
   - Firestore Database → созед → **Rules** → мӯҳтавои `firestore.rules`-ро гузоред → Publish.
   - Project settings → Your apps → Web (`</>`) → `firebaseConfig`-ро нусха кунед.
2. **GitHub:** репозитории нав. Ҳамаи файлҳоро боргузорӣ кунед. `firebase-config.js`-ро бо маълумоти худ иваз кунед. `build-apk.yml`-ро ба роҳи `.github/workflows/build-apk.yml` гузоред.
3. **Actions → Build APK → Run workflow.** Баъд аз ~6 дақиқа: APK дар **Releases** ва версияи веб дар шохаи `gh-pages`.
4. **Версияи веб:** Settings → Pages → Branch: `gh-pages` → Save. Суроға: `https://НОМ.github.io/РЕПО/`. Ин суроғаро дар Firebase → Authentication → Settings → **Authorized domains** илова кунед. Дар Chrome «Add to Home screen».
5. **Бори аввал:** барномаро кушоед → «Ҳисоби аввалини маъмур»-ро созед (ID ва парол ≥ 8 аломат; ID танҳо ҳарф, рақам, `_` ё `-`).
6. Маъмур: Назорат → **«Сохтани 11 қисми физика»** (11 курс, баста ва маводи намунавӣ). Баъд «Бештар → Пардохт» (WhatsApp ва ҳамён)-ро пур кунед.

## Харид ва дастрасӣ
Хонанда «Харидани курс» → WhatsApp бо матни тайёр (ID, ном, курс, нарх) кушода мешавад → ӯ пулро ба ҳамёни шумо мефиристад → шумо дар «Пардохт» **«Тасдиқи пардохт»** ва алоҳида **«Додани иҷозат ба курс»**-ро мезанед. «Бекор кардани иҷозат» дастрасиро бозпас мегирад. Мундариҷаи курси пулакӣ танҳо бо қоидаҳои сервер ба хонандаи дорои иҷозат хонда мешавад.

## Нав кардани барнома
Файлро дар GitHub иваз кунед → Actions → Run workflow → APK-и нав. Версияи веб худаш нав мешавад (тугмаи «Навсозӣ» дар Танзимот).

## Чӣ сохта шуд ва чӣ НЕ (ҳақиқатан)
**Сохта ва дар браузер бо пойгоҳи озмоишӣ санҷида шуд:** ID/парол, сабти ном, ворид шудан, барқарорсозии парол тавассути маъмур, 11 қисм, курси ройгон/пулакӣ, баста, тахфиф, дарсҳои видео (пайванд) бо «анҷом ёфт», китоб/назария, тест (4 вариант, баҳо, тавзеҳ, такрор, таърих), масъалаҳои қадамбақадам, харид тавассути WhatsApp, ҳолатҳои дархост, тасдиқ ва додани иҷозати ҷудо, бекор кардан, кабинет, эълонҳо, омор, даромад, журнали амал, нусхаи эҳтиётӣ, тоҷикӣ/русӣ, ҳолати торик, Android APK.

**Сохта НАШУД (марҳилаи 2/3):** имтиҳони вақтдор ва олимпиада, рейтинг, сертификат, калькулятори илмӣ, ҷадвали формулаҳо, конвертери воҳидҳо, луғат, графикҳои ҳаракат, симуляторҳо, савол-ҷавоб бо устод, зеркашии офлайн, огоҳиҳои push.

**Маҳдудиятҳо:**
- Қоидаҳои Firestore ва вуруди воқеӣ дар Firebase аз ҷониби ман санҷида нашуданд (дар муҳити ман ба Firebase дастрасӣ нест) — бори аввал ҳатман худатон озмоиш кунед; агар хатои «permission-denied» дидед, ба ман нависед.
- Пайванди видео (YouTube/Vimeo) аз ҷониби хонанда мубодила шуда метавонад. Муҳофизати воқеӣ хидмати махсус (Bunny/Vimeo/Cloudflare Stream) мехоҳад.
- Пардохт дастӣ аст; тасдиқ — аз ҷониби маъмур.
- APK «debug» аст: калиди имзо байни сохтҳо метавонад фарқ кунад — ҳангоми навсозӣ шояд лозим шавад APK-и пештараро нест кунед. Play Protect: «Install anyway».
- Дар Play Market нашр нашудааст.
